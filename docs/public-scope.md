# Public / Proprietary Boundary

This repository exists to demonstrate the engineering work without publishing company intellectual property.

## Included

- generic YOLO inference
- ByteTrack integration
- track-state representation
- selected-track visualization
- configuration loading
- metrics and benchmarking
- tests
- architecture and verification documentation

## Not included

- Vayuron proprietary source code
- production guidance or control implementation
- vehicle actuation commands
- navigation/control laws
- operational interception logic
- private datasets or camera footage
- trained production weights
- credentials, tokens, or internal network configuration

The public code is therefore best read as an inspectable reconstruction of the perception/software-engineering responsibilities rather than a copy of the production system.
